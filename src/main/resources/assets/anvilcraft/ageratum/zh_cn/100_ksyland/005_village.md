# 村民

游商可通过砸击转化为村民。

详情请参考[村民](../001_feature/001_villager.md)。

# <ref item="anvilcraft:jewelcrafting_table"/>

制作<ref item="anvilcraft:jewelcrafting_table"/>，让村民转职为[珠宝匠](../001_feature/001_jeweler.md)。

# <ref item="anvilcraft:geode"/>

- 可向珠宝匠购买<ref item="anvilcraft:geode"/>。
- 将其敲碎可获得<ref item="anvilcraft:topaz"/>，这是进入下一阶段的必需材料。
