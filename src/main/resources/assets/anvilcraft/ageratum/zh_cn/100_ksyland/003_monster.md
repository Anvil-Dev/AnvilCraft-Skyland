# 怪物生成

- 以僵尸为例：在主世界中，除*蘑菇岛*群系外，它会在天空光照小于或等于 7、方块光照为 0 的有效位置生成。
- 收集一些方块，在距离自己至少 24 格的位置铺设平台，即可开始刷怪。
- 获得更多材料后，可以尝试建造*游走刷怪塔*。
- 手动击杀僵尸有概率掉落<ref item="minecraft:iron_ingot"/>，这是推进发展的必需材料。

# <ref item="anvilcraft:seeds_pack"/>

- 手动击杀僵尸还可能掉落<ref item="anvilcraft:seeds_pack"/>。
- 右键打开它，有概率获得多种种子，其中包括<ref item="minecraft:pumpkin"/>。
