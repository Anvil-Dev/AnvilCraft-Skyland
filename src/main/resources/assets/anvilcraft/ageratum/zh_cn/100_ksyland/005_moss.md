# <ref item="skyland:pebble"/>

- 将<ref item="minecraft:cobblestone"/>放在*潮湿生物群系*中，保持光照为 0，并确保其上方为空气。
- <ref item="minecraft:cobblestone"/>会缓慢转化为<ref item="minecraft:mossy_cobblestone"/>。
- 使用斧头可从中刮下<ref item="skyland:moss"/>。

# <ref item="minecraft:azalea"/>

- 对<ref item="minecraft:moss_block"/>使用<ref item="minecraft:bone_meal"/>，有概率长出<ref item="minecraft:azalea"/>。
- 对<ref item="minecraft:azalea"/>使用<ref item="minecraft:bone_meal"/>，有概率长成树木。
- 至此，你终于可以获得大量木材。

# 更多<ref item="minecraft:dirt"/>

- 先获得<ref item="minecraft:stone"/>；无论是通过烧制，还是让熔岩接触水源方块均可。
- 对<ref item="minecraft:moss_block"/>使用<ref item="minecraft:bone_meal"/>，使其同化周围的<ref item="minecraft:stone"/>。
- 在<ref item="minecraft:moss_block"/>上种植<ref item="minecraft:azalea"/>，即可生成<ref item="minecraft:rooted_dirt"/>。
- 使用锄头耕作<ref item="minecraft:rooted_dirt"/>，即可获得<ref item="minecraft:dirt"/>。
- 与直接消耗<ref item="minecraft:dirt"/>相比，这种方法可节省大量<ref item="skyland:stone_anvil"/>。
