# 回归铁砧工艺主线

- 接下来的发展请参考“铁砧工艺手册/主线流程”。
- 大多数物品在原版中均有较为稀有的获取方式。
- 本章仅介绍本附属或铁砧工艺本体新增稀有物品的获取途径。
- 对于部分重要的原版获取方式，也会在此简要说明。

# <ref item="minecraft:quartz"/>

有两种获取方式：

1. 与猪灵交易，获得<ref item="minecraft:quartz"/>。
2. 与石匠村民交易，获得<ref item="minecraft:quartz_block"/>后再将其分解为<ref item="minecraft:quartz"/>。

# <ref item="minecraft:nether_star"/>

- 前往下界，寻找*下界结构*并建造刷怪塔，以获取<ref item="minecraft:wither_skeleton_skull"/>。
- 前往下界，与猪灵交易以获得<ref item="minecraft:soul_sand"/>。
