# <ref item="minecraft:budding_amethyst"/>

- 泥土下埋藏着<ref item="minecraft:budding_amethyst"/>。
- 当相邻位置为空气时，<ref item="minecraft:budding_amethyst"/>会缓慢生长出<ref item="minecraft:small_amethyst_bud"/>。
- <ref item="minecraft:small_amethyst_bud"/>最终会成长为<ref item="minecraft:amethyst_cluster"/>；挖掘后可获得<ref item="minecraft:amethyst_shard"/>。

# 紫水晶工具

利用紫水晶可制作<ref item="anvilcraft:amethyst_sword"/>等一系列工具，它们比木制工具更强。

<warning>
请勿破坏<ref item="minecraft:budding_amethyst"/>。即使使用精准采集，也无法完整回收它。
</warning>
