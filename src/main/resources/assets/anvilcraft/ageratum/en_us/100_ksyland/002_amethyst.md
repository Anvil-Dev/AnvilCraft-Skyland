# <ref item="minecraft:budding_amethyst"/>

- <ref item="minecraft:budding_amethyst"/> is buried beneath the dirt.
- When an adjacent space is air, <ref item="minecraft:budding_amethyst"/> slowly grows <ref item="minecraft:small_amethyst_bud"/>.
- <ref item="minecraft:small_amethyst_bud"/> eventually grows into an <ref item="minecraft:amethyst_cluster"/>, which drops <ref item="minecraft:amethyst_shard"/> when mined.

# Amethyst Tools

Amethyst can be used to craft <ref item="anvilcraft:amethyst_sword"/> and other tools that are stronger than wooden tools.

<warning>
Do not break <ref item="minecraft:budding_amethyst"/>. It cannot be collected intact, even with Silk Touch.
</warning>
