# Villagers

A wandering trader can be crushed into a villager.

See [Villagers](../001_feature/001_villager.md) for details.

# <ref item="anvilcraft:jewelcrafting_table"/>

Craft an <ref item="anvilcraft:jewelcrafting_table"/> to turn a villager into a [Jeweler](../001_feature/001_jeweler.md).

# <ref item="anvilcraft:geode"/>

- You can buy <ref item="anvilcraft:geode"/> from a Jeweler.
- Crush it to obtain <ref item="anvilcraft:topaz"/>, which is required for the next stage.
