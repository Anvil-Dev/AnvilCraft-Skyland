# Mob Spawning

- Zombies, for example, can spawn at valid locations in the Overworld with sky light level 7 or lower and block light level 0, except in *Mushroom Fields* biomes.
- Gather some blocks and build a platform at least 24 blocks away from yourself to start spawning mobs.
- Once you have more materials, consider building a *mob farm*.
- Killing zombies by hand has a chance to drop <ref item="minecraft:iron_ingot"/>, an essential resource for further progress.

# <ref item="anvilcraft:seeds_pack"/>

- Killing zombies by hand can also drop <ref item="anvilcraft:seeds_pack"/>.
- Right-click it for a chance to receive various seeds, including <ref item="minecraft:pumpkin"/>.
